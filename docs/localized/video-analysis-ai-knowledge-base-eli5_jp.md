# AI知識倉庫 ELI5

> 日本語読者版 · [詳細な原文](../../video-analysis-ai-knowledge-base-eli5.html)

全文入力、ベクトル検索、SQL、グラフDBをかご・計算機・地図の比喩で説明します。

## 要点

- 質問が少ないなら文書を丸ごと渡す方法が簡単です。
- 一つの文章を探すならベクトル・キーワード検索が得意です。
- 合計・平均・件数はSQLなどのDBに計算させます。
- 人・店舗・メニューの関係にはグラフとCypherが有用です。
- 混合質問にはルーターとフォールバックを使います。

## 共通原則

ローカル優先、安全なメモリ余裕、検証済みアーティファクト、ランタイム中立契約、明示的承認、根拠記録を基本とします。
