# Gemma 4 12B Video Analysis

> English reader edition · [Canonical source](../../video-analysis-gemma4-12b-mac-mini.md)

A review of memory, speed, multimodal, and API experiments from a video running Gemma 4 12B in LM Studio on a 16GB M4 Mac mini.

## Key points

- Model file size differs from real peak RAM.
- Separate official maximum context, runtime limit, and device-safe context.
- OCR capability does not guarantee business accuracy.
- LM Studio is an optional desktop adapter candidate, not a mobile solution.
- Measure TTFT, prefill, decode speed, and memory after installation.

## Shared principles

Defaults are local-first execution, safe memory headroom, verified artifacts, runtime-neutral contracts, explicit approval, and evidence records.
